เชื่อมต่อ Gemini API

🔒 คำเตือนด้านความปลอดภัย: API Key จะถูกเก็บในเบราว์เซอร์ (localStorage) ผู้ที่เข้าถึงเครื่องนี้สามารถดู Key ได้ ผ่าน DevTools ควรใช้ Key ที่มีสิทธิ์จำกัดเท่านั้น และห้ามใช้กับเครื่องสาธารณะ

คู่มือการใช้งาน

1. ตั้งค่ารายชื่อ

เพิ่มชื่อ-นามสกุล และอัปโหลดภาพประจำตัว รูปถูกเก็บใน IndexedDB แยกจาก localStorage

2. การแจ้งเตือน

ระบบจะแจ้งเตือนตามเวลาที่เลือก โดยต้องเปิดแท็บนี้อยู่ หากปิดแท็บหรือเบราว์เซอร์จะไม่แจ้งเตือน

3. สำรองข้อมูล

ดาวน์โหลดไฟล์ JSON เก็บไว้เป็นประจำ ไฟล์สำรองจะรวมข้อมูลทั้งหมด (ไม่รวม API Key และรูปภาพ)

4. ปรึกษา AI

ตั้งค่า Gemini API Key เพื่อใช้ AI จริง ระบบจะส่งข้อมูลนัดหมายล่วงหน้าและประวัติการสนทนาไปด้วย เพื่อให้ AI ตอบได้ตรงบริบทและจำบทสนทนาก่อนหน้าได้
